# ASSETS — Digital Marketing & SEO Specialist Portfolio

## 1. Asset rules
- Use the owner’s real portrait only when supplied and approved.
- Use real project screenshots only with permission and with confidential data removed.
- Never fabricate client logos, campaign dashboards, rankings, certificates, reviews, or analytics results.
- Use licensed or original images.
- Keep all important text as live website text, not embedded in images.
- Optimize images as WebP/AVIF where supported and provide descriptive alt text.

The final brand name is not yet confirmed, so create a flexible symbol and editable wordmark layout without inventing a name. Explore a subtle combination of search/magnifier, connected digital nodes, and upward progress. Use deep navy with a restrained blue or teal accent. ## 5. Technical asset guidance
- Hero: 1600×900 or similar 16:9.
- Service illustrations: 800×800.
- Portfolio thumbnails: 1200×900 (4:3) or consistent project ratio.
- Blog covers: 1200×675 (16:9).
- Logo: SVG preferred, PNG fallback.
- Favicon: SVG and PNG sizes as required.
- Lazy-load below-the-fold imagery.
- Set intrinsic dimensions or aspect ratio to reduce layout shift.
- Use responsive image sizes and compress assets.
